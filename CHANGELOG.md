# Changelog

## 0.1.0

- First release of the Openhandle node for n8n.
- Instagram, TikTok, X, and Reddit resources, generated from the Openhandle OpenAPI contract.
- URL resource that reads the data behind a supported social link.
- Freshness field on every operation.
- Return All and Max Pages for paginated list operations.
- Openhandle API credential with a free test request.
